# AI Playground 
Welcome to my AI playground, where I break things so you don’t have to.

This repo exists because I decided to dive into the world of AI agents and workflows, mostly by following online courses taught by people who apparently assume everyone has an unlimited OpenAI budget.

I, however, do not.

So instead of sacrificing my wallet to the API gods, I’ve rerouted everything to use Ollama, because:

- it runs locally
- it costs $0
- and my electricity bill is slightly cheaper than OpenAI tokens
- and I have more than enough time (to wait)

This repository is basically a collection of scripts, experiments, half‑baked ideas, and occasional strokes of brilliance as I learn to build AI agents, tools, and workflows. Think of it as my personal AI jungle gym, sometimes elegant, sometimes chaotic, always educational.

Expect rough edges. Expect hacks. Expect comments like "I'll fix this later" (I probably won't).
But hey, progress is progress!
